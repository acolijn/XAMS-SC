# Web UI

Server-rendered HTML, a meta refresh, no JavaScript framework and no build
step — so that in three years a student can change it without installing a
toolchain. Binds to `127.0.0.1`, never `0.0.0.0`.

Pages: Overview, Channels, P&I mimic, High voltage, Logs. This manual is
served by the same process, at `/manual`.
